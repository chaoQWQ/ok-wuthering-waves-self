# 多账号日常 QQ 邮箱通知

多账号日常结束后发送一封汇总邮件，包含开始/结束时间、耗时、每次账号尝试的成功、失败或中断状态。异常退出和手动停止也会尝试发送；强制结束进程、断电无法发送。成功表示 DailyTask 正常返回，不代表额外核验了游戏内每项奖励。跳过或未执行的账号不会计入成功；账号配置未匹配后的重新选择会作为另一次尝试记录。

在 QQ 邮箱设置中开启 SMTP 服务并取得授权码。使用授权码，不要使用 QQ 登录密码。按以下名称在 Windows 用户环境变量中配置，然后完全退出并重新启动程序（定时任务也需要读取这些变量）：

| 环境变量 | 内容 |
| --- | --- |
| `WW_DAILY_EMAIL_ENABLED` | `1` 启用；删除或改为 `0` 关闭 |
| `WW_DAILY_EMAIL_SENDER` | 发件 QQ 邮箱，例如 `123456@qq.com` |
| `WW_DAILY_EMAIL_AUTH_CODE` | 该邮箱的 SMTP 授权码 |
| `WW_DAILY_EMAIL_TO` | 收件邮箱；留空则发给自己 |

连接使用 `smtp.qq.com:465`，SSL/TLS 加密并验证服务器证书。授权码仅从环境变量读取，不写入任务配置或日志；环境变量不是加密保险箱，请仅在可信 Windows 用户下配置。不要将授权码提交到 Git 或发送到聊天中。

下一次运行多账号日常时生效。发信失败只记录一条不含凭据的警告，不影响日常结果，也不会自动重试。邮件仅包含账号标识和状态，不附带截图、游戏凭据或原始异常日志。
