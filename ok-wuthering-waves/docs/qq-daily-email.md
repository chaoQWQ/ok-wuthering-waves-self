# 多账号日常 QQ 邮箱通知

多账号日常结束后发送一封汇总邮件，包含开始/结束时间、耗时、每次账号尝试的成功、失败或中断状态，以及已识别的活跃度和活跃度奖励领取结果。账号成功或失败按照日常任务执行结果统计。每个账号单独列出奖励状态和说明，包括已全部领取、未全部领取、未确认、未检测或检测异常。异常退出和手动停止也会尝试发送；强制结束进程、断电无法发送。跳过或未执行的账号不会计入成功；账号配置未匹配后的重新选择会作为另一次尝试记录。

活跃度奖励在全部日常和附加任务结束后再次领取并检查。附加任务报错时也会执行这次领取和检查。邮件分别显示任务执行结果和奖励领取结果，例如“账号 3：成功，活跃度奖励：未全部领取”，或“账号 3：失败，活跃度奖励：已全部领取”。

在 QQ 邮箱设置中开启 SMTP 服务并取得授权码。使用授权码，不要使用 QQ 登录密码。在「多账号日常任务」配置中打开「邮件通知」，填写下列字段：

| 任务配置项 | 内容 |
| --- | --- |
| 邮件通知 | 开关；关闭后不发送，即使环境变量曾启用通知 |
| QQ 发件邮箱 | 发件 QQ 邮箱，例如 `123456@qq.com` |
| QQ 邮箱 SMTP 授权码 | 该邮箱的 SMTP 授权码 |
| 收件邮箱 | 收件邮箱；留空则发给自己 |

连接使用 `smtp.qq.com:465`，SSL/TLS 加密并验证服务器证书。配置保存在本机 `configs/MultiAccountDailyTask.json`（Git 已忽略），授权码为明文，请勿分享该文件。代码默认关闭通知且不包含个人邮箱凭据；本机预填值通过本地配置保存。修改本地配置文件后需重启程序读取，界面内修改按任务配置机制保存。

下一次运行多账号日常时生效。发信失败只记录一条不含凭据的警告，不影响日常结果，也不会自动重试。邮件包含账号标识、状态、活跃度和奖励领取验证结果，不附带截图、游戏凭据或原始异常日志。
