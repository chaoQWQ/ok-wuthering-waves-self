# 地图视图与角色位置

大地图使用独立的视图中心和比例绘制标点。截图识别提供绝对坐标，地形图像跟踪提供两次识别之间的画面平移和缩放。静止画面保持同一张地形参考图，重复识别产生的小范围坐标变化经过图像核对后处理。

WGC 图像采集线程以每秒最多 30 次的频率读取游戏截图，Qt 显示线程读取最近的图像状态。定位任务进行特征匹配期间，图标、路线和点击区域继续按照实际地形更新。每次识别结果绑定对应的原始截图和采集时间，发布时补充处理已经收到的新画面。

地形跟踪使用 OpenCV 光流、双向位置检查、RANSAC 和分布于多个区域的特征。小地图排除中心人物图标、明亮图标和高饱和颜色区域。识别结果与地形证据之间的小范围差异保持现有图像投影，较大的坐标变化需要连续确认。地图编号、账号或者截图尺寸改变后重新建立图像参考。

绝对定位结果最多保留 6 秒，同时要求最近 0.75 秒内具有有效图像证据。超过时间限制后隐藏画面，图像跟踪不会无限延长绝对定位结果的有效期。其他截图方式按定位任务收到的截图更新。

截图坐标以游戏画面的像素为单位，Qt 窗口几何使用 Windows 逻辑像素。小地图绘制时统一转换整个画面；大地图图标、路线和点击区域使用同一显示缩放比例。125% 等 Windows 显示缩放设置参与坐标换算。

状态面板的「玩家坐标」来自当前启用的 OCR 或库街区坐标渠道。「视图中心」单独显示当前大地图中心。拖动大地图不会改变角色坐标或角色到目标的距离。查看与角色所在地图不同的地图时，角色坐标和目标距离显示「未知」。

回到大世界后，角色位置继续更新，程序清除大地图的视图缓存。图像匹配不会写入角色位置的 OCR 历史。

大地图的当前线路使用 Qt 置顶窗口绘制连线和方向箭头，整个窗口允许鼠标事件穿透到游戏。退出大地图或关闭线路显示时，连线窗口隐藏。

小地图资源图标、当前目标、状态面板和「收集提示」由同一个 Qt 窗口显示。提示内容自动获取当前目标的网页说明和第一张参考图片。切换目标后更新内容，图片下载完成后通过 GUI 线程显示，下载结果保存在本地缓存。显示请求合并为最近一帧，隐藏请求检查当前显示代数。

参考图片使用收集目标保存的地图编号。地图识别暂时没有结果、方向或距离刷新时，保留当前目标的说明和图片。窗口暂时隐藏后保留已加载的内容，恢复显示时继续使用；清除或切换收集目标后更新内容。

当前环境验证命令：

```powershell
..\.venv\Scripts\python.exe -X utf8 -m pytest tests/test_image_anchor.py tests/TestMinimapStability.py tests/TestOverlayMotion.py tests/TestCoordinateOcr.py
..\.venv\Scripts\python.exe -X utf8 -m tests.verify_bigmap_snapshot "游戏大地图截图的绝对路径"
..\.venv\Scripts\python.exe -X utf8 tools/verify_overlay_capture.py --seconds 4
..\.venv\Scripts\python.exe -X utf8 tools/verify_map_task_display.py --seconds 8
```

`test_image_anchor` 使用真实地图截图验证几何误差、静止图像、较晚返回的定位结果、地图切换与 Qt 显示缩放。截图验证使用下载的 SIFTGZ 特征数据进行真实匹配。两个 `verify_` 工具读取实际游戏 WGC 截图并将诊断结果保存到 `logs`，运行期间不发送游戏输入。完整任务诊断使用独立配置目录，不更改游戏账号或收集记录。
