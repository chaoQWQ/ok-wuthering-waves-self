# 收集账号管理

在「实时触发 → 地图高价值物品显示 → 收集账号管理」点击「管理账号」。

- 搜索账号：按 UID 或账号名称筛选列表。
- 添加账号：输入新的 UID 或自定义名称，点击「添加账号」，程序会使用该档案。重复名称无法添加。
- 编辑账号名称：选择账号，修改输入框内容，点击「编辑账号名称」。原有已完成标点保留。
- 切换档案：选择账号，点击「使用选中账号」。也可以使用设置页面的「收集记录账号」下拉框。
- 查看记录：列表显示每个账号的已完成标点总数，并注明当前使用的档案。
- 删除账号：选择账号，点击「删除账号」，确认后删除该档案及其收集记录。删除当前使用的档案后，程序会选择剩余列表中的第一个档案。

默认档案同样可以改名和删除。账号名称最多 64 个字符。新增档案的收集记录为空，每个档案独立保存，重命名会保留记录。删除最后一个档案时，程序会创建空白默认档案，供后续保存收集记录。

修改账号名称和删除账号前，程序会自动备份完整收集记录数据库，备份保存到 `assets/stitched/account_backups`。备份保存失败时，操作会终止，已有记录保留。删除后，管理窗口显示备份文件路径。

这些档案只管理本地收集进度。切换游戏登录账号后，需要选择对应档案。程序不会通过此界面登录或切换游戏账号，也不会上传账号信息。

切换档案时，程序会重新读取对应的已完成标点并更新收集目标；库街区路线按对应账号的完成记录选择目标。
