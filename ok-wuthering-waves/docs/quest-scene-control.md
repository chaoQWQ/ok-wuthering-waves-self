# 剧情地形与机关处理

`QuestSceneState` 保存目标上下关系、移动与高度进展、攀爬体力、当前对象和等待状态。`QuestTraversalController` 保存地形决策、镜头调整结果和受阻记录。目标、场景或已确认的位置发生变化后重新观察。

## 地形操作

- 距离旁的上下箭头通过 OCR 与局部颜色形状检测识别。世界目标在画面中的高度作为观察信息。
- 普通导航每次移动最多 0.4 秒，接近目标时最多 0.2 秒。持续输入每隔最多 0.2 秒取得画面，检查前台窗口、剧情、战斗与小地图。
- 同一位置最多尝试两次跳跃。攀爬使用本地坐标、环境运动和体力环检查进展；无法读取的信息保存为 `unknown`。
- 视觉决策可选择可见墙面的横向移动或退出攀爬。横向尝试最多两次；正常高度进展会更新该记录。
- 后退路线完成后重新观察。黄色圈中心存在上下提示时，需要确认上下通路才能继续区域搜索。

## 机关处理

`QuestPuzzleSession` 保存对象身份、已完成步骤、携带状态和失败次数。对象关联使用名称、本地位置与 ORB 图像匹配。多个同名对象无法区分时终止操作并报告原因。

每个 `PuzzleStep` 包含 `preconditions`、`action`、`expected_effect` 和 `timeout`。普通操作完成后观察 3 秒，有动画时观察至 8 秒。任务变化、对应机关文字或视觉状态变化，以及进入对白或机关界面，可作为相应步骤的成功依据。

内置处理器包括：

- `InteractionHandler`：F 对话、调查、开关、拾取、放置及旋转交互。
- `ExplicitControlHandler`：界面明确显示的 E、T、Q、F 操作；支持显示持续时间的按住操作。
- `SequenceHandler`：提示中明确列出数字顺序的机关，逐次确认结果。
- `PanelHandler`：提示明确指定名称的界面按钮。
- `AttackHandler`：任务明确要求的攻击操作。

需要图案、连线、路径或其他具体规则的机关，通过 `QuestPuzzleSession.register(handler)` 注册 `PuzzleHandler`。处理器可以读取 `PuzzleObservation.frame` 进行本地模板或颜色检测，并在 `effect` 中返回该步骤允许的成功结果。缺少规则时报告缺少的对象或控制说明。

同一对象与相同环境状态下，连续两次没有产生预期效果，停止重复操作。程序异常直接报告；模型请求次数与操作历史保留。战斗中断操作后，重新检查场景，不自动重放输入。

## 模型与隐私

JEV 接收经过特征码清理的任务、交互、地形、机关和动作结果。模型只能选择当前提供的动作；返回后重新检查任务与交互条件。

`Allow Vision Screenshots` 默认关闭。开启并配置视觉服务后，可以发送已遮蔽特征码的截图，用于地形判断和机关前后比较。组合对比图中的两张截图分别遮蔽后再编码。图像编码不会修改本地原始画面。

## 验证

`TestQuestSceneControl` 使用真实游戏截图、OCR 与已记录 JEV 响应，检查 NPC 交互验证、重复失败、地形决策、攀爬体力、方向箭头、确认界面暂停和特征码遮蔽。`verify_quest_interaction_runtime` 使用任务运行环境检查四种分辨率下的实际截图。

实际游戏限时检查遇到模拟领域及结束确认界面。确认界面的小地图检测返回不可见，禁止继续世界移动。该次运行未取得剧情机关、特殊地形通行或剧情战斗衔接的完整验证证据。
