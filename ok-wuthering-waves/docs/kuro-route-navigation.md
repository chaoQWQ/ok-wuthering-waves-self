# 库街区路线导航

## 使用

1. 打开 OK-WW dev，在「实时触发」启用「地图高价值物品显示」。
2. 选择「收集记录账号」，启用「世界地图覆盖层」和「显示状态面板」。
3. 点击「库街区路线广场」，输入路线名称并按 Enter，或者点击搜索按钮。
4. 在「当前地图」范围选择最热排序或最新排序。选择「全部地图」时，结果使用库街区跨地图搜索的相关性排序。
5. 点击路线查看作者说明，默认选择线路一，点击「加载路线」。加载后自动启用「库街区路线导航」。
6. 启动实时触发任务，在游戏内打开大地图完成地图识别，再关闭大地图跟随小地图方向提示进行探索。

路线按作者提供的节点顺序导航。大地图显示节点编号和连接线；小地图显示附近路线节点、当前目标方向及距离。路线作者说明和本地资源中的点位说明用于辅助探索。

大地图右上角可直接选择线路。所选线路的节点、连接线和方向箭头显示在地图上，导航从该线路第一个未完成点开始。再次打开大地图时保留当前线路选择。

大地图单击资源点或路线节点，可查看库街区提供的点位说明和参考图片。存在多张图片时，使用「上一张」「下一张」切换，图片下方显示当前序号与总数。没有图片或请求失败时，详情窗口显示对应提示。

点位详情和图片在后台获取，参考图片缓存在本地。移动地图或关闭详情后，已经结束显示的点位请求不会重新打开详情。

## 确认与进度

- 手动完成当前点的收集后，关闭大地图并使用「收集物确认快捷键」。确认距离限制沿用现有设置。
- 确认会保存当前账号的完成记录，并选择路线下一个未完成点。
- 「推进快捷键」跳过当前节点，不写入完成记录。信标和经过点也可以使用此操作。
- 大地图右键点击节点可切换该节点的完成标记。
- 重新启动程序或者重新加载路线时，从第一个未完成节点继续。只跳过、未确认的节点仍然属于未完成节点。
- 切换账号时读取对应账号的记录。不同路线中相同的点位编号共用该账号的完成记录。
- 「库街区路线导航」关闭后，可使用「收集物搜寻」进行附近物品导航。

到达目标不会自动判定领取。路线连接线表达节点顺序；实际道路、攀爬、传送、战斗和解谜操作由玩家完成。

## 数据与账号安全

搜索、路线加载和点位详情使用库街区公开接口。所选路线内容保存在本地任务配置中，启动程序后可继续使用已加载内容；领取记录保存在本地账号档案中。

此功能使用既有截图定位和屏幕覆盖层显示。没有新增游戏进程内存访问、DLL 注入、游戏客户端 API hooking、游戏网络数据包修改或移动操作。库街区请求不包含本地记录账号、游戏登录信息或者游戏凭据。第三方辅助工具的封号风险无法保证为零。
