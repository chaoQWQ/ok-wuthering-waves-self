# 多账号日常任务状态

登录等待最多持续 180 秒。登录超时后，任务记录该账号的失败状态，关闭并重新启动游戏，打开账号列表，继续处理其他账号。本次执行中，每个失败账号只尝试一次；再次启动任务时可以重新尝试。

游戏重新启动后，任务识别标题界面的账号入口。已登录时点击切换账号并确认登出，显示“登入”时点击该按钮打开账号列表，随后选择下一个账号。

游戏重新启动失败、无法打开账号列表或用户停止任务时，任务立即终止并保留已经保存的状态。

每个账号的状态保存在任务配置所在目录的 `multi_account_daily_state.sqlite3` 文件中，包括执行中、成功、失败、登录超时和中断。任务使用 SQLite 保存状态，每次尝试结束后立即提交。

任务界面的“账号每日状态”显示当天各账号的状态。程序异常退出后，再次启动任务时会将未结束的执行记录标记为中断。

每天按照北京时间 04:00 划分。当天成功的账号在重复执行时自动跳过，下一天可以重新执行。任务同时记录登录列表中的账号名称和游戏内识别到的 Profile Code，启动时已经处于游戏世界也可以检查完成状态。

DailyTask 在体力副本和声骸相关任务结束后尝试领取活跃度奖励，随后处理游戏邮件、通行证和附加任务。全部日常任务结束后再次领取，并重新打开活跃度页面，记录活跃度数值，检查 20、40、60、80、100 五档奖励的领取完成图标。

账号每日状态按照日常任务执行结果保存：日常任务正常结束记录成功，任务执行报错记录失败。活跃度奖励领取结果作为每个账号的独立汇报项，显示已全部领取、未全部领取、未确认、未检测或检测异常，并记录相关说明。

日常任务或附加任务报错时，任务仍会尝试再次领取和检查奖励，然后继续报告原有任务异常。奖励领取或检测报错时单独记录奖励结果。用户停止任务时立即终止；游戏窗口在日常任务期间断开时按任务失败处理，在奖励检查期间断开时记录奖励检测异常并重新启动游戏切换账号。

失败、登录超时和中断状态允许下次重新尝试。成功状态会保留，后续失败记录不会覆盖当天的成功状态。

状态记录从此功能启用后开始保存。
