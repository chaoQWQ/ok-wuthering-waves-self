# 多账号日常任务状态

登录等待最多持续 180 秒。登录超时后，任务记录该账号的失败状态，关闭并重新启动游戏，打开账号列表，继续处理其他账号。本次执行中，每个失败账号只尝试一次；再次启动任务时可以重新尝试。

游戏重新启动失败、无法打开账号列表或用户停止任务时，任务立即终止并保留已经保存的状态。

每个账号的状态保存在任务配置所在目录的 `multi_account_daily_state.sqlite3` 文件中，包括执行中、成功、失败、登录超时和中断。任务使用 SQLite 保存状态，每次尝试结束后立即提交。

任务界面的“账号每日状态”显示当天各账号的状态。程序异常退出后，再次启动任务时会将未结束的执行记录标记为中断。

每天按照北京时间 04:00 划分。当天成功的账号在重复执行时自动跳过，下一天可以重新执行。任务同时记录登录列表中的账号名称和游戏内识别到的 Profile Code，启动时已经处于游戏世界也可以检查完成状态。

只有整个 DailyTask 成功返回才记录成功。失败、登录超时和中断状态允许下次重新尝试。成功状态会保留，后续失败记录不会覆盖当天的成功状态。

状态记录从此功能启用后开始保存。
